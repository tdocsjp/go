# チュートリアル: Go モジュールを作成する

これは、Go 言語の基本的な機能のいくつかを紹介するチュートリアルの最初のパートです。Go を使い始めたばかりなら、`go` コマンドや Go モジュール、ごく簡単な Go のコードを紹介している [チュートリアル: Go を始める](/doc/tutorial/getting-started) もぜひ見てください。

このチュートリアルでは、2つのモジュールを作成します。1つめは、他のライブラリやアプリケーションからインポートされることを意図したライブラリです。2つめは、1つめを利用する呼び出し側のアプリケーションです。

このチュートリアルの一連の流れには、言語の異なる部分をそれぞれ示す7つの短いトピックが含まれます。

1. モジュールを作成する -- 他のモジュールから呼び出せる関数を持つ、小さなモジュールを書きます。
2. [別のモジュールからコードを呼び出す](/doc/tutorial/call-module-code) -- 新しいモジュールをインポートして使います。
3. [エラーを返して処理する](/doc/tutorial/handle-errors) -- 簡単なエラー処理を追加します。
4. [ランダムな挨拶を返す](/doc/tutorial/random-greeting) -- スライス（Go の動的サイズの配列）でデータを扱います。
5. [複数人への挨拶を返す](/doc/tutorial/greetings-multiple-people) -- マップにキーと値のペアを保存します。
6. [テストを追加する](/doc/tutorial/add-a-test) -- Go 組み込みのユニットテスト機能を使ってコードをテストします。
7. [アプリケーションをコンパイルしてインストールする](/doc/tutorial/compile-install) -- コードをローカルでコンパイルしてインストールします。

> **Note:** 他のチュートリアルについては [Tutorials](/doc/tutorial/) を参照してください。

## 前提条件

- **多少のプログラミング経験。** ここで出てくるコードはかなり単純ですが、関数・ループ・配列についての知識があると役立ちます。
- **Go。** このチュートリアルを進めるには、最新バージョンの Go を使うことをお勧めします。インストール方法については [Go のインストール](/doc/install) を参照してください。
- **コードを編集するツール。** お使いのテキストエディタなら何でも構いません。多くのテキストエディタは Go を十分にサポートしています。よく使われるのは VSCode（無料）、GoLand（有料）、Vim（無料）です。
- **コマンド端末。** Go は Linux・Mac のどのターミナルでも、Windows の PowerShell や cmd でも問題なく動作します。

## 他の人が使えるモジュールを始める

まず Go モジュールを作成しましょう。モジュールでは、ひとまとまりの有用な機能のために、関連する1つ以上のパッケージを集めます。例えば、財務分析のための関数を持つパッケージをモジュールとして作成すれば、財務アプリケーションを書く他の人があなたの成果を使えるようになります。モジュールの開発についての詳細は、[モジュールの開発と公開](/doc/modules/developing) を参照してください。

Go のコードはパッケージにまとめられ、パッケージはモジュールにまとめられます。モジュールは、Go のバージョンや必要とする他のモジュールの集合など、コードの実行に必要な依存関係を指定します。

モジュールの機能を追加・改善していくと、そのモジュールの新しいバージョンを公開することになります。モジュールの関数を呼び出すコードを書く開発者は、モジュールの更新されたパッケージをインポートし、本番環境に投入する前に新しいバージョンでテストできます。

1. コマンドプロンプトを開き、ホームディレクトリに `cd` します。

   Linux や Mac の場合:

   ```
   cd
   ```

   Windows の場合:

   ```
   cd %HOMEPATH%
   ```

2. Go モジュールのソースコード用に `greetings` ディレクトリを作成します。

   例えば、ホームディレクトリから次のコマンドを使います。

   ```
   mkdir greetings
   cd greetings
   ```

3. [`go mod init` コマンド](/ref/mod#go-mod-init) を使ってモジュールを開始します。

   `go mod init` コマンドを実行し、モジュールパスを指定します -- ここでは `example.com/greetings` を使います。モジュールを公開する場合、このパスは Go のツールがそのモジュールをダウンロードできる場所でなければ*なりません*。それは、コードのリポジトリの場所になります。

   モジュールパスによるモジュールの命名についての詳細は、[依存関係の管理](/doc/modules/managing-dependencies#naming_module) を参照してください。

   ```
   $ go mod init example.com/greetings
   go: creating new go.mod: module example.com/greetings
   ```

   `go mod init` コマンドは、コードの依存関係を追跡するための go.mod ファイルを作成します。今のところ、このファイルにはモジュールの名前と、コードが対応する Go のバージョンしか含まれていません。しかし依存関係を追加していくと、go.mod ファイルにはコードが依存するバージョンが一覧として記載されるようになります。これにより、ビルドの再現性が保たれ、どのモジュールバージョンを使うかを直接制御できます。

4. テキストエディタで、コードを書くためのファイルを作成し、greetings.go と名付けます。

5. 次のコードを greetings.go ファイルに貼り付けて保存します。

   ```go
   package greetings

   import "fmt"

   // Hello returns a greeting for the named person.
   func Hello(name string) string {
       // Return a greeting that embeds the name in a message.
       message := fmt.Sprintf("Hi, %v. Welcome!", name)
       return message
   }
   ```

   これがモジュールの最初のコードです。呼び出し元の求めに応じて挨拶を返します。次のステップでは、この関数を呼び出すコードを書きます。

   このコードでは、次のことをしています。

   - 関連する関数を集めるための `greetings` パッケージを宣言しています。
   - 挨拶を返す `Hello` 関数を実装しています。

     この関数は、`string` 型の `name` パラメータを受け取ります。関数も `string` を返します。Go では、名前が大文字で始まる関数は、同じパッケージ内にない関数からも呼び出せます。これは Go では「エクスポートされた名前」と呼ばれます。エクスポートされた名前についての詳細は、Go のツアーの [Exported names](/tour/basics/3) を参照してください。

   - 挨拶を保持する `message` 変数を宣言しています。

     Go では、`:=` 演算子は変数の宣言と初期化を1行で行うための短縮記法です（Go は右辺の値から変数の型を決定します）。長く書くなら、次のように書けます。

     ```
     var message string
     message = fmt.Sprintf("Hi, %v. Welcome!", name)
     ```

   - `fmt` パッケージの [`Sprintf` 関数](https://pkg.go.dev/fmt/#Sprintf) を使って挨拶メッセージを作成しています。最初の引数はフォーマット文字列で、`Sprintf` は `%v` フォーマット verb を `name` パラメータの値に置き換えます。`name` パラメータの値を挿入することで、挨拶文が完成します。
   - 整形された挨拶文を呼び出し元に返しています。

# まとめと参考情報

このチュートリアルでは、関数を書き、それを2つのモジュールにまとめました。1つは挨拶を送るロジックを持つモジュールで、もう1つはそれを利用する側のモジュールです。

> **Note:** このトピックは [Go モジュールを作成する](/doc/tutorial/create-module) から始まる、複数パートからなるチュートリアルの一部です。

コード内の依存関係の管理についての詳細は、[依存関係の管理](/doc/modules/managing-dependencies) を参照してください。他の人が使えるモジュールの開発についての詳細は、[モジュールの開発と公開](/doc/modules/developing) を参照してください。

Go 言語のさらに多くの機能については、[A Tour of Go](/tour/) を見てみてください。
